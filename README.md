# 🌸 BeautyMart - منصة توريد مستحضرات التجميل بالجملة (B2B Wholesale Store)

منصة تجارة إلكترونية متكاملة بنظام B2B مخصصة لتوريد مستحضرات التجميل والعناية بالبشرة والشعر للصالونات، مراكز التجميل، ومتاجر التجزئة بأسعار الجملة المباشرة.

---

## 🚀 المميزات الرئيسية (Key Features)

### 🏢 نظام الجملة المتكامل (B2B Features)
- **الحد الأدنى لقيمة الطلب (MOV):** تطبيق حد أدنى لإجمالي الطلب بقيمة 1,000 ج.م مع شريط تقدم تفاعلي في السلة وحماية صفحة الدفع.
- **الحد الأدنى لكمية المنتج (MOQ):** تحديد أقل كمية يمكن طلبها لكل منتج (مثلاً 6 أو 12 قطعة).
- **وحدات التعبئة والتغليف (Packaging Units):** دعم الطلب بنظام الدستة (12 قطعة) والكرتونة (24 أو 72 قطعة) مع أزرار زيادة سريعة.
- **أسعار الجملة المتدرجة (Tiered Wholesale Pricing):** تخفيضات تصاعدية تلقائية عند شراء كميات أكبر (Tier 1 & Tier 2) مع حساب التوفير فورياً.
- **حسابات الأنشطة التجارية:** تسجيل بيانات اسم المتجر/الصالون، السجل التجاري، والرقم الضريبي.

### 🛡️ الأمان والحماية (Security & Reliability)
- **حماية تامة ضد ثغرات IDOR:** تأمين واجهات السلة والطلبات ولوحة الإدارة والتحقق من ملكية الجلسات.
- **معاملات آمنة ومنع البيع بالسالب (Race Conditions):** حسم المخزون ذرياً داخل db.transaction لمنع أي تضارب عند الطلبات المتزامنة.
- **التحقق من صحة البيانات:** باستخدام مكتبة Zod لكافة مدخلات النماذج وواجهات الـ API.

### 🛒 تجربة تسوق سلسة (UX & Performance)
- **سلة الزوار (Guest Cart):** حفظ المنتجات في المتصفح ومزامنتها تلقائياً عند تسجيل الدخول دون فقدان أي صنف.
- **لوحة تحكم إدارية متكاملة (/admin):** إدارة كاملة للمنتجات (إضافة، تعديل، حذف، تحديد مستويات أسعار الجملة، ومراقبة المخزون).
- **تصفح سريع بدون إعادة تحميل:** باستخدام Next.js App Router و <Link> مع خيارات تصفية وترتيب متقدمة.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
- **Frontend:** [React 19](https://react.dev/), [Tailwind CSS v4](https://tailwindcss.com/)
- **Database & ORM:** [PostgreSQL](https://www.postgresql.org/), [Drizzle ORM](https://orm.drizzle.team/)
- **Authentication:** JWT (Jose), Bcrypt.js
- **Validation:** [Zod](https://zod.dev/)

## ⚙️ التشغيل المحلي (Getting Started)

1. **تثبيت الحزم:**
   \\\ash
   npm install
   \\\

2. **إعداد متغيرات البيئة:**
   أنشئ ملف \.env\ وأضف:
   \\\env
   DATABASE_URL=postgresql://postgres:postgres@localhost:5432/app_db
   JWT_SECRET=your-secret-key-here
   \\\

3. **تطبيق قاعدة البيانات وتغذيتها:**
   \\\ash
   npx tsx src/db/seed.ts
   \\\

4. **تشغيل خادم التطوير:**
   \\\ash
   npm run dev
   \\\
   افتح [http://localhost:3000](http://localhost:3000) في المتصفح.
